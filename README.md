
# Jay Louise B. Cediño — Personal Portfolio

A responsive personal portfolio website built using **HTML5, CSS3, and Vanilla JavaScript**. It showcases personal information, skills, projects, and other relevant details through a clean, modern, and user-friendly interface.

## About the Project

This personal portfolio website serves as an online platform to present personal information, technical skills, and project experiences. It features a responsive layout and interactive elements designed to provide a smooth browsing experience across desktop and mobile devices.

## Technologies Used

- **HTML5** – Structures the content and layout of the website.
- **CSS3** – Handles the visual design, styling, animations, and responsive layouts.
- **Vanilla JavaScript** – Provides interactive functionality and user interface behavior.
- **Google Fonts** – Enhances typography and visual presentation.

## Key Features

- **Responsive Design** – Adapts to different screen sizes, including desktops, tablets, and mobile devices.
- **Pastel Blue Color Palette** – Uses a refined pastel-blue theme with brighter blue and cyan accents.
- **Interactive Navigation** – Provides responsive navigation for easier website browsing.
- **Scroll Reveal Effects** – Adds visual transitions as content appears while scrolling.
- **Project Overview Interactions** – Provides interactive elements for presenting project information.
- **Enhanced Visual Design** – Includes gradients, shadows, borders, improved contrast, and hover effects.
- **Mobile-Friendly Layout** – Maintains usability and readability across different devices.

## How to Run Locally

No build tools or additional installation are required.

Follow these steps to open the portfolio on your computer:

1. Download or clone the repository.
2. Extract the ZIP file if you downloaded the project as a ZIP archive.
3. Make sure the required files are kept together in the project directory.
4. Open `index.html` using a modern web browser.
