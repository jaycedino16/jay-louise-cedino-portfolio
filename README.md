# Jay Louise B. Cedino — Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Open locally
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. Open `index.html` in a modern browser.

## What's updated
- Refined pastel-blue palette with slightly brighter blue and cyan accents.
- Cleaner contrast, gradients, shadows, borders, and hover states.
- Preserved the existing layout, content, profile image, and project-card structure.
- Responsive navigation and mobile layouts.
- Scroll reveal and project overview interactions.

No build tools or installation are required. Google Fonts loads when an internet connection is available; fallback fonts are included.
